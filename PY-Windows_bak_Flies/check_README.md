# Python 版本检查与升级 · 工作流程

> 用途：运行脚本 → 检查 Python 版本 → 按需升级到指定版本
> 流程共 4 步，其中第 2 步含版本判断分支。

## 流程总览

| 步骤  | 阶段   | 动作                                  |
| --- | ---- | ----------------------------------- |
| 1   | 启动   | 运行脚本                                |
| 2   | 版本检查 | 检查 Python 版本并判断（> 3.11 结束；否则询问是否升级） |
| 3   | 选择版本 | 提供 10 个版本号供用户选择                     |
| 4   | 执行升级 | 按所选版本进行升级                           |

## 详细步骤

### 第 1 步：运行脚本

- 启动脚本。

### 第 2 步：检查 Python 版本

- 检查电脑调用的 Python 版本，并将结果告知用户。
- **判断分支**：
  - 若版本**高于 3.11** → **结束脚本**；
  - 若版本**不高于 3.11** → 告知当前 Python 版本号，并询问是否需要升级：
    - 用户回答 **N** → 退出脚本；
    - 用户回答 **Y** → 进入第 3 步。

### 第 3 步：选择升级版本

- 询问用户需要升级到的版本号，并给出 **10 个版本号**供其选择。

### 第 4 步：执行升级

- 用户选定版本后，按所选版本号执行升级。
